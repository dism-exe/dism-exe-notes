# 1 dism_notes

General purpose notes repository for reverse engineering mmbn games

# Reading the notes

Note files are in markdown format and can be edited with a text editor.

This repository is also an obsidian vault. You can get obsidian at https://obsidian.md/.

To view the notes in the browser, go to the [webview branch](https://github.com/dism-exe/dism-exe-notes/tree/webview).

# Contributor now pages

A now page describes what the contributor is currently focused on primarily, but can also link to other notes written by the contributor.

* [lan/now.md](https://github.com/dism-exe/dism-exe-notes/blob/webview/lan/now.md)
